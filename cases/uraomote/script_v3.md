# 《裏表ラバーズ》PV 剧本 v3 ——「二次元の表、三次元の裏」

> 占位曲：Pheebie 翻唱版（原曲 wowaka），181.0 秒，约 161 BPM，4/4 拍，1 小节约 1.49 秒。换成 SVC 转换版后按同一节拍网格重排。
> v3 改动：全片的主轴从“微缩模型印进杂志”改成 **2D 与 3D 互相侵入**。v2.3 的六个 3D 场景（S1–S6）、物件、材质和光线设定继续有效，是“3D 那一面”，这里只写改动（第 4 节）。
> 她的插画用开源模型生成（2026-10 选型见第 6 节）。模型许可都是非商用；这支 PV 只私下使用，没有问题，但公开商用前要换掉插画。

## 0. 核心概念

### 0.1 一句话

她的「表」是一张**二次元插画**：扁平、完美、套色印刷出来的那张脸，是她给世界看的样子。她的「裏」是 1:12 的**三次元微缩世界**：有灰尘、有雨、有重量，是她不给人看的部分。
被一种来路不明的爱感染之后，两个维度开始互相渗漏：2D 闯进 3D，3D 从 2D 的缝里涌出来，同一个镜头里一个物件在 2D 和 3D 之间来回闪。到最后，表和裏翻了面。

### 0.2 三条铁律

1. **两种质感绝不混合**。2D 永远是孔版印刷品：生成り纸 `#F1E9D6` 或黑画纸 `#121116`，四色墨（藏青 `#1E2236`、朱 `#E0301E`、荧光粉 `#FF3D8B`、黄 `#F4C21B`），带网点、套印偏移、油墨斑驳和裁切线。3D 永远是微缩实拍质感：Cycles、浅景深、真实材质。两者之间的落差就是看点。
2. **每个镜头至少一次“维度事件”**（第 1 节的七种手法之一）。没有越界的镜头不留。
3. **越界卡在节拍上**：重拍切换，反拍回弹。副歌里每一拍都要有一次。

## 1. 七种维度手法

| 代号 | 手法 | 画面 | 做法 |
|---|---|---|---|
| **D1 窗** | 2D 里开 3D 的窗 | 主视觉上的大字“裏”“表”、心形、漫画分格、她的剪影、她的瞳孔，都是镂空的窗，窗里是活的 3D 场景 | 纸是 3D 空间里的一张平面，开孔；微缩场景真的摆在纸后面，所以镜头一动就有视差。镜头可以穿过窗口飞进场景，纸的切口擦过镜头 |
| **D2 占** | 3D 被 2D 占据 | 天空、远景、窗外、屏幕、招牌、自动售货机面板、车窗，全换成印刷品或 2D 动画 | 印刷品做成对镜头不可见的发光背板，负责给 3D 打光、进入反射；镜头看到的那一份是清晰的 2D，在合成里垫在 3D 后面。2D 的透视线和 3D 的消失点对齐 |
| **D3 立** | 2D 片立在 3D 里 | 巨大的拟声词（ドクン、ジリリ、ザァァ、ガタンゴトン）、对话框、箭头、她的纸板人偶，立在场景中 | 带透明通道的发光平面：照亮周围，倒映在积水里，雨从它前面落下，3D 物体会挡住它 |
| **D4 闪** | 同一镜头内 2D ↔ 3D 闪回 | 3D 物件在重拍上闪成自己的印刷版 2 帧再回来；2D 字形在重拍上挤出厚度变成实体，下一拍压回平面 | 3D→2D：用物件遮罩把该物件的渲染分色成四色墨加网点，替换 2 帧，可以是单个物件也可以是整个画面。2D→3D：文字和形状的挤出深度打关键帧（0 → 3 cm → 0），实体用漆面材质 |
| **D5 粒** | 粒子 | 网点（扁平圆片，四色墨）在 3D 空间里飞；孔版纸屑；光束里的灰尘；雨在重拍上变成印刷速度线；小心脏灯泡和扁平心形贴纸混在一起 | 几何节点散布；网点和纸屑永远正对镜头，只有朝向变化时会露出纸的厚度 |
| **D6 翻** | 纸的转场 | 一帧 3D 画面被印成网点纸，再翻页、撕开、折叠，露出下一个场景 | 画面印成网点纸，贴到一张纸的平面上，用布料或骨骼做弯曲 |
| **D7 视** | 机位 | 见 1.1 | — |

### 1.1 机位规则（v3 新增）

- **正上方平铺**：镜头垂直向下，3D 物件摆在一张 2D 印刷页上。这是 2D 和 3D 同框时最有平面设计感的角度，每段至少一次。
- **绕到侧面**：绕着一张 2D 纸片转 90°，纸片变成一条线，后面的 3D 场景露出来；继续转，看到纸背（没印东西的纸板和铅笔编号）。用来揭示“她是纸”。
- **穿窗推进**：穿过 D1 的窗，4 帧，强动态模糊，纸的切口擦过镜头。
- **甩镜跨界**：横向甩镜头，画面从 3D 场景甩进一张印刷页（或反过来），甩的过程中，纸边作为真实物体从镜头前掠过。
- **冲击推拉**：副歌每拍推 3%，0.12 秒衰减（动态分镜里已经实现）。
- **跨维度焦点转移**：前景 2D 纸片清晰、3D 虚化，焦点再拉到 3D 上；纸片虚成色块。
- **荷兰角**：副歌 2 每小节换一次倾斜方向，±12°。
- **希区柯克变焦**：只用一次，副歌 1 最后一小节，对着心脏。

## 2. 她（二次元）

### 2.1 出镜规则

- **她的脸只在 2D 里出现。** 3D 世界里只有她留下的痕迹（耳机线、帆布鞋、指纹、喝了一半的牛奶），或者她的纸板人偶。
- 纸板人偶是她在 3D 里的样子：插画印在 0.3 mm 卡纸上，刀口露出纸芯白；逆光时会透光，能看到背面的铅笔编号。动作靠逐张替换（一拍二，每秒 12 张），换张时有 1–2° 的随机晃动。
- **「表」的她**：生成り纸，四色墨，表情平静、完美，像偶像海报。
- **「裏」的她**：黑画纸加荧光墨，同一个姿势，内层的荧光粉头发露出来，表情是真实的那一面（慌张、发烧般的眼神）。

### 2.2 外形（沿用 v2.3）

齐耳短波波头，外层墨黑，内层挑染荧光粉（平时藏着）。左侧别一枚缺口心形的朱红发夹。深藏青水手服，领子两条白线，领结是朱红耳机线打的。外面套大一号的米白开衫，袖口长过指尖，左肘一块歪扭的朱红补丁。百褶裙到膝上，有一块荧光粉墨渍。白色中筒袜。

### 2.3 需要的插画（全部生成后统一分色成孔版四色）

| # | 内容 | 用在 |
|---|---|---|
| KV | 主视觉：她站在画面右侧，抱着一颗比她上身还大的扁平心形，正面偏 3/4 | P0、P8、全片的“表” |
| KV' | 同一构图的「裏」版：黑底、荧光墨、头发内层露出、表情不同 | P5、P8 |
| H1–H2 | 手：伸出、按下 | S1 按闹钟 |
| B1–B3 | 电话亭里的背影：静止、起风、头发扬起露出内层 | S4 |
| R1–R6 | 跑步的腿和裙摆，6 张循环（膝盖以下，侧面） | S5 |
| J1–J2 | 跳进车门的背影 | S5 |
| E1 | 眼睛特写（瞳孔是一扇窗） | P0、P3 |
| F1–F8 | 表情序列（钟罩里的“脑内”翻页） | S2 |

一致性：先定 KV，再以 KV 为参考图生成其他张（参考图编辑），发型、发夹、领结、补丁必须每张对得上。

## 3. 分镜（按段落）

小节号是动态分镜里的重拍序号。

### P0 前奏「表紙」0:00–0:15（小节 0–8）

1. **印出来**（0–2 小节）：黑场。每一拍印一个墨版：黄 → 粉 → 朱 → 藏青，像孔版机过纸，套印偏移逐拍收敛，第 8 拍对准。成品是 KV：她在右，左侧竖排巨大的“裏”“表”，中间一颗心形。（D6）
2. **原来是纸**（2–5 小节）：正交镜头悄悄换成 35 mm 透视，开始横移。原来 KV 是悬在空中的一张纸，“表”字、“裏”字和心形都是镂空的：“表”里是 S1 清晨的卧室，“裏”里是 S6 粉色的倒置房间（同一个房间的表与裏），心形里是 S3 工坊的表里心脏。视差证明它们真的在纸后面。（D1）
3. **她被抠出来**（5–7 小节）：每个重拍，KV 上的她从纸面上被抠出来 2 帧，变成有厚度的纸板人偶，在纸上投下影子，再贴回去。（D4）
4. **穿窗**（第 8 小节）：镜头急推进心形窗口，4 帧穿过纸面进入 S3；纸的切口擦过镜头，心脏在纸后面升起。（D1 + D7）

### P1 主歌 1「目覚め」0:15–0:36（小节 8–22）

1. **闹钟**（8–11）：100 mm 微距滑过闹钟（动态分镜的机位）。7:00 的重拍，闹钟闪成自己的印刷版 2 帧，这是全片第一次维度事件（D4）。铃响时，铃铛上方弹出 2D 拟声词“ジリリ”，随铃锤一下一下抖。（D3）
2. **手**（11–12）：她的 2D 手（H1 → H2）从画面右侧伸进 3D 画面，按住闹钟。纸板的手在铁皮上投下真实的影子；按下的瞬间爆出一个印刷的冲击星，闹钟上留下一个朱色指纹（印在 3D 物件上的 2D）。
3. **全景**（12–15）：后拉，露出布景箱。窗外是印刷天空：藏青网点渐变、条纹的朝阳、横向漂移的霞云，能看到纸边和图钉（D2）。布景箱其实立在一张巨大的 KV 印刷页上，页面的字从箱底下穿过。
4. **手机**（15–16）：正上方平铺，看床头的手机。屏幕是 2D 动画：一条“♡”通知；通知一点开，一串扁平的纸心从屏幕里倒出来，落进 3D 房间，落在被子上弹了一下。（D2 + D5 + D7）
5. **主观**（16–18）：枕头高度看向窗户，焦点从前景的纸心拉到窗外的印刷天空（跨维度焦点转移）。
6. **钟罩**（18–22）：100 mm 隔着玻璃看钟罩内部：“脑内”的纸条每一拍翻一张，翻出她的一个表情（F1–F8），像翻页动画，2D 关在 3D 的玻璃里。环绕镜头时，钟罩后面的实验室墙是一张巨大的心脏解剖图印刷品（D2）。

### P2 导歌「ヒビ」0:36–0:53（小节 22–33）

横移逐渐加速，每一次横移都跨过维度边界。

1. **S2 → S4**（22–26）：从钟罩横移出去，一张挂着的印刷页从镜头前掠过（页上印的是钟罩的网点版），掠过之后已经在 S4 的雨巷里（甩镜跨界）。
2. **S4**（26–30）：横移经过电话亭。自动售货机的面板是 2D 的她，在饮料按钮之间眨眼（D2）。巷子上空立着“ザァァ”的雨声拟声词，雨从它前面落下（D3）。
3. **S5**（30–31）：站台远景。印刷的夕阳世界（概念帧 2）里，霞云和太阳的条纹在快速滑动；2D 在动，3D 站台纹丝不动。（D2）
4. **漫画页**（31–33）：一张四格漫画页，每一格都是 3D 窗。每一拍有一格的边框裂开，3D 从格子里溢到纸上：闹钟从第一格滚出来，掉在纸面上；第三格的雨把纸面打湿，网点晕开。（D1 → D3）最后一拍，四格同时翻面进副歌。（D6）

### P3 副歌 1「ドクン」0:53–1:19（小节 33–51）

S3 工坊和表里心脏，每一拍一次维度事件。每小节的节拍型：
- **第 1 拍**：冲击推进，心脏闪成 KV 上的扁平心形 2 帧；
- **第 2 拍**：从切断的血管里喷出网点粒子，扁平圆片在 3D 空间里飞散；
- **第 3 拍**：巨大的 2D“ドクン”砸进工坊（D3）；
- **第 4 拍**：“ドクン”挤出 3 cm 厚，变成朱红烤漆的实体字，投下影子，下一小节第一拍再压回纸片（D4）。

镜头（每小节换一个）：
1. 微距、全景、环绕、三分之四侧（动态分镜里已有，景深已修好）；
2. **绕到侧面**：晾干架上挂着她的大幅印刷像（KV）。镜头绕过去，她变成一条线，线后面是心脏，再继续转到纸背。（D3 + D7）
3. **正上方平铺**：工作台上铺满印刷页，3D 心脏躺在 KV 的心形上，两颗心一 2D 一 3D 重叠，每拍互换哪颗在上面。
4. **插入 S4**（39、45 小节）：雨伞、垂下的听筒，旁边弹出对话框“もしもし？”（D3）。
5. **“再见”那一句**：画面中央开一个圆形的窗（D1），窗里是 S4 的听筒特写，窗外继续轰炸。
6. **最后一小节**：对着心脏做一次希区柯克变焦，背景的工坊被拉开，露出后面的 2D 印刷世界。

### P4 间奏「雨」1:19–1:45（小节 51–68）

S4 的长镜头（动态分镜的机位），加上概念帧 3 的全部手法：印刷夜空和条纹月亮（D2），电话亭后面高出墙头的“ドクン”（D3），对话框。

1. **她在亭子里**：电话亭里立着她的背影纸板（B1），被亭灯从上面照亮，投下薄薄的影子；逆光时纸透光，能看到背面的铅笔编号。
2. **起风**（推进到一半）：顶灯箱一闪，纸板换成 B2、B3，头发的外层被掀开，**内层的荧光粉第一次露出来**，在玻璃上反射出一道粉。
3. **绕到侧面**：镜头绕电话亭转 90°，她变成一条线，再转过去是没印东西的纸板背面。全片第一次明确告诉观众：“她是纸”。
4. **最后一小节**：她的纸板滑出画面，听筒（3D）垂下摆动。重拍上，3D 的雨变成 2D 的印刷速度线一小节，再变回来（D4 + D5）。

### P5 主歌 2「裏返り」1:45–2:06（小节 68–82）

S6 颠倒的房间，「裏」的印版：黑画纸、荧光墨。
1. **窗外**：黑纸上的荧光粉网点天空，一轮粉色条纹月亮（D2）。
2. **墙纸剥落**：每个重拍剥落一块墙纸，后面露出来的是 KV' 的局部，裏版的她的眼睛、头发内层（D2 + D1）。
3. **手机**：屏幕上的 KV' 在故障闪烁。
4. **四格页·裏**：黑纸荧光墨，四格是 S6 的 3D 窗，格线像泡过水一样弯曲变形。
5. 家具开始上浮（3D），小心脏灯泡和 2D 纸心混在一起往上飘（D5）。

### P6 导歌 2「乱反射」2:06–2:12（小节 82–86）

半小节一切，所有场景轮一遍（动态分镜里已有）。每一切先落在该场景的印刷版上，半拍后变成 3D，像维度的频闪（D4）。纸屑风暴越来越密（D5），最后一拍，纸屑在空中排成电车的剪影，接副歌 2。

### P7 副歌 2「あっち」2:12–2:31（小节 86–98）

S5 站台：3D 站台是一座岛，四周是印刷的世界（概念帧 2）。每小节在「表」（夕阳印刷世界）和「裏」（黑纸、粉月、青星）之间翻一次，翻的是整个印刷世界，3D 站台保持不动，只换光（D2 + D4）。荷兰角每小节换方向。

1. **跑**：贴地 24 mm，她的 2D 腿（R1–R6 循环）踩过 3D 的盲道砖，纸板的影子落在砖上。她跑出画面，留下那双白帆布鞋（3D），鞋尖对齐白线。（D3）
2. **鞋**：100 mm 微距，左鞋头的圆珠笔心是 2D 印上去的，每一拍被荧光粉渗透一圈（2D 长在 3D 上）。
3. **电车进站**：奶白加朱红的电车（3D）进站，“ガタンゴトン”的拟声词纸片跟着车厢一起滑进来（D3）。车窗全是 2D：每扇窗里是她的一格插画，电车像一条移动的胶片（D2）。
4. **“立刻去那边”**：从车厢里往外拍。她的背影纸板（J1、J2）跳进车门；门关上，夹住朱红耳机线；电车启动，耳机线被拉直，从书包里整根抽走。
5. **离站**：车窗里的插画拉成光的拖影，同时叠上 2D 速度线（D5）。指示牌的 3D 箭头乱转，天空里印的 2D 箭头同步乱转。

### P8 尾奏「裏表紙」2:31–3:01（小节 98–结束）

1. **崩塌**：S6 倒挂的房间里家具往上坠落，小心脏像雪（动态分镜里已有），镜头滚转 180°。
2. **碎裂**：表里心脏落地，沿裂缝碎开。碎片飞向镜头，在半空中翻成 2D 纸屑（3D → 2D，D4）。
3. **拼回**：正上方平铺。纸屑落在一张黑纸上，拼成 KV 的背面：「裏表紙」。从背面看，“裏”“表”两个窗口是反字，窗后的 3D 场景一个个熄灯。
4. **合上**：封底合上，翻转 180°。中央只剩一个极小的荧光粉色页码“0”。黑。

## 4. 场景改动（相对 v2.3）

## 6. 制作管线

1. **2D**：`scripts/riso.py`（PIL）画所有印刷品，包括天空、拟声词、对话框、页面和分色后的插画，输出 PNG（带透明通道）。在 Blender 里做成发光平面（D3），或者作为合成层（D1、D2）。
2. **她的插画**：AutoDL 上的 ComfyUI。2026-10-21 查的排行榜：
   - Artificial Analysis 开源权重文生图榜（T2I v2.1）第一是 Qwen-Image-2.1（Elo 1042，2026-09）。这个榜没有二次元分类。
   - 二次元专用模型最新的是 Anima（CircleStone Labs 与 Comfy Org，20 亿参数，2026-05-15 正式版）。
   - 两个都用同一段提示词测试，选出更好的。插画生成后分色成四色墨加网点，和其他 2D 统一。
3. **3D**：Cycles（4090D），场景脚本沿用 S1–S6。
   - D4 的 3D → 2D：用物件遮罩把渲染分色。
   - D4 的 2D → 3D：挤出深度打关键帧。
4. **顺序**：
   1. 插画选型，出 KV；
   2. 动态分镜 v2：把 v3 的镜头和维度事件放进现有的 animatic.py；
   3. 逐场景出定帧，确认质感；
   4. 正式渲染。
