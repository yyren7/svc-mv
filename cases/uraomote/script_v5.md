# 《裏表ラバーズ》PV 剧本 v5 ——「天与水之间」

> 占位曲：Pheebie 翻唱版（原曲 wowaka），181.0 秒，约 161 BPM，4/4 拍，1 小节约 1.49 秒。段落表沿用 v4 第 4 节的实测（`audio/urao_timing.json`）。
> v5 推翻 v4 的前提。v4 把三维做成一座挂满两面印刷的她的"晾画大厅"，那是为了让画有地方挂而造出来的容器：等大、等距、夹子、白边，怎么打光都是一间海报仓库，三维空间自己没有构图。v5 的三维世界里几乎什么都没有：一整片天、一整面像镜子的水、一条地平线、一道光，水里立着一面墙，墙上一扇窗，窗台上一杯水。她画里本来就有的天空、水面、窗玻璃、镜子，就是这片真的天和真的水；三维的东西（墨、雨、涟漪、碎片、发丝、光）进到她画里有立体感的部分。没有房间，没有挂着的画。
> 她的插画沿用 v4 第 3 节的造型和已经画好的那一套（KV、A1–A5、Q1、C1–C4、W1、W2、U1、U2、U4、R0、F1、F2、S1–S3）。模型许可都是非商用，公开商用前要换掉插画。

---

## 0. 核心

### 0.1 一句话

世界只有天和水。水面是一张纸：从天这一边看是她的「表」——白天、晨光、安静、完美；水面之下是她的「裏」——夜、墨、发烫的那一面。一滴来路不明的墨落进窗台上的一杯水，又从杯子落进整片海，裏从水底往上长，表和裏之间那层水面裂开、碎掉、掀起、撕开，最后天在上也在下，她在两片天之间，表裏一体。

### 0.2 情节

她一个人站在一扇窗前，窗开在一面立在水里的墙上，墙外没有别的东西。晨光从墙后升起，穿过墙上镂空的「表」「裏」两个字，照出她。一滴墨落进她窗台上那杯水里——是爱，来路不明。墨从杯子里的水渗进她脚下的水，整片海的水底开始泛红；她的倒影不再是她，是她不给人看的那一面。入夜，世界翻过来，裏成了世界；水面在她脚下碎成千百片镜子，每一片里是她的一个瞬间。她在水面上奔跑，撞穿自己的画；海像一张纸被掀起、撕开，撕开的外面是天。她在两片天之间跃起，一边是冷光一边是红光。碎纸落下，水面重新静止，墙的倒影里那两个字反过来读：裏表。

### 0.3 三条铁律

1. **两种质感绝不混合。** 二维是精致的二次元插画，有线稿，画在纸上。三维是 Cycles 实拍质感：水、天、灰泥、玻璃、墨、雨、光，没有线稿。落差就是看点。
2. **画的平面就是世界的平面。** 她画里的窗玻璃、水面、镜子、瞳孔，不是贴图，是这个世界真的天和水：镜头一动就有视差，云会走，雨会落进去，倒影是真的。反过来，三维只进入画里有立体感的地方：头发、脸、衣服、墨、雨。
3. **越界卡在节拍上。** 重拍切换，反拍回弹。主歌每小节最多一次维度事件，riff 和导歌加速，副歌每拍一次，终段每半拍。

### 0.4 不用的东西

- 任何形式的爱心、漫画拟声词、漫画符号。"ドクン"是水面上的一圈环。
- 日常道具：闹钟、鞋、电车、电话亭、雨伞、手机。全片唯一的物件是那杯水。
- 房间、走廊、仓库、挂着的画、夹子、钢丝。她不是挂在哪里的一张海报，她站在世界里。
- 扁平的孔版插画、画里的文字。

## 1. 世界

### 1.1 几何（米，真实尺寸）

| 东西 | 做法 |
|---|---|
| 水 | 无边的一面水（半径 2 km 的圆），3 cm 深的近黑水在黑底上：白天是天的镜子，夜里是黑镜。表面有极慢的细纹；节拍上一圈脉冲环；雨落下时满面是小环。它是「表」和「裏」之间那张纸：会裂（P1 末）、碎（P8）、掀起（P9 末）、撕开（P10） |
| 天 | 半径 1 km 的穹顶，贴她的天空画（D2）：S1 黎明（表）、S2 雨夜（裏）、S3 终段。天给世界打光，也整个倒映在水里。太阳 / 月亮是一盏日光灯，方向跟画 |
| 墙 | 一面旧灰泥墙立在水里，原点处，8 m 宽、6 m 高、0.4 m 厚，面朝 −Y（她这一边）。墙上一扇高窗（2.4 × 3.6 m，中心偏右 x = +1.2，窗台高 0.9，细钢框，老玻璃），窗左侧上下排着镂空的「表」「裏」两个字（各 0.7 m，x = −2.6，z = 3.9 / 2.9），光从墙后穿过字和窗照过来。墙在水里有一个完整的倒影。墙是全片唯一的建筑 |
| 杯 | 窗台上一杯清水（高 10 cm）。P1 的第一滴墨落在这里；俯拍时杯口就是海的地平线（1.5 节的尺度跳跃） |
| 深水 | 水面之下是深水：暗、带体积光（光从水面漏下来成柱），墨在里面翻涌发光。副歌和 C 系列插画在这里 |
| 她 | 二维。两种在场方式见第 2 节 |

### 1.2 尺度与构图准则

- 全片只有一个物件（墙）和一个人。远景里她很小、天和水很大；近景里她占满画幅。两种尺度之间来回跳是节奏的一部分。
- 每个三维镜头都有三层：近处的水面、中景的墙或她、远处的天。留白至少占画面六成。
- 地平线放在三分之一或二分之一；对称靠倒影；一点透视只对着那扇窗。
- 一个场景只有一个光的方向（黎明在墙后；夜里玫瑰色在水底；雨夜只有窗里的光）。全片唯一的暖色是墨。
- 水面高度的镜头是全片的"主机位"：镜头贴着水、半浸在水里、从水下仰看，都是从这张纸的两面看她。

### 1.3 色彩

| | 颜色 |
|---|---|
| 表 | 纸白 `#F2F0EB`、晨蓝 `#BCD3E6`、雾灰蓝 `#8696A8` |
| 裏 | 墨黑 `#0E0D12`、深靛 `#141B2E` |
| 墨 | 玫瑰红 `#F0285A`，发光处 `#FF5C8A` |

开场没有颜色，只有晨光里的白和蓝；红从那一滴墨起，一段一段从水底往上长；终段冷光和红光各占半边天。

## 2. 她在世界里的两种在场

| 方式 | 是什么 | 用在 |
|---|---|---|
| **站在世界里** | 插画里的她抠出来（anime-seg 的人物遮罩），带深度浮雕的一张薄纸，站 / 躺 / 跑在水面上，三维的光照她，水里有她的倒影；从侧面看是一条线、从背面看是白纸和铅笔编号（她是纸）。头发是三维发丝 | 所有三维镜头：KV 站在窗前、W1 在雨里、U1 躺在夜的水上、R0 在水面上跑、F1 在两片天之间 |
| **进入画里** | 整张插画占满画面，画里的窗、镜、水、瞳孔换成世界真的天和水（视差、云、雨、倒影），头发、脸、衣服起成浮雕，墨从头发渗、雨落在脸前、发丝离开纸面 | 所有二维镜头：A1–A5、Q1、C1–C4、W2、U2、U4、R0 的正面冲、F1、F2 |

二维镜头不再有纸边和白边；画幅就是画。从"进入画里"退出来，就是镜头退到她站着的地方：画里的窗退成墙上的那扇窗，画里的水退成脚下的海。

倒影是另一个人（P3、P7）：水只对反射光线显示另一张画（她的裏），相机直视她看到的是表——v4 验证过的做法（只对 glossy 可见的自发光面）。

## 3. 七种维度手法

| 代号 | 手法 | v5 的画面 |
|---|---|---|
| **D1 窗** | 二维里开三维的窗 | 画里的窗玻璃、镜子、她的瞳孔里是真的天和地平线；墙上镂空的表 / 裏两个字是光 |
| **D2 占** | 三维被二维占据 | 天是画出来的（S1 / S2 / S3），给世界打光、倒映在水里 |
| **D3 立** | 二维立在三维里 | 她的纸人站在水上，有倒影，侧看是一条线 |
| **D4 闪** | 同一镜头内来回闪 | 重拍上整帧闪成纸上的负片一帧；倒影在裏和表之间闪；同一股墨从画里流进海里 |
| **D5 粒** | 粒子 | 墨、雨、水面的环、水面碎片、碎纸、光里的尘 |
| **D6 翻** | 纸的转场 | 水面是纸：裂、碎、掀起、撕开；她的画只撕一次（P9 末） |
| **D7 视** | 机位 | 见 3.1 |

### 3.1 机位规则

- **水面高度**：镜头贴着水、半浸在水里（画面上半是表的世界、下半是裏的深水）、从水下仰看。每段至少一次。
- **正上方**：垂直向下看水面。每段至少一次。
- **穿窗推进**：穿过墙上的窗或画里的窗，4 帧，纸的切口擦过镜头。
- **甩镜跨界**：横向甩镜，从世界甩进一张画的正面，再甩出来。
- **绕到侧面**：绕着她的纸人转 90°，她变成一条线；再转到背面是白纸。
- **冲击推拉**：副歌每拍推 3%，0.12 秒衰减。
- **跨维度焦点转移**：前景的她（二维）清楚、后景的三维虚，再把焦点拉过去。
- **荷兰角**：副歌 2 每小节换向，±12°。
- **滚转 180°**：只用一次（P7 开头），世界翻过来。
- **希区柯克变焦**：只用一次（P5 末），对着站在窗前的她。

## 5. 分镜

每条标出小节、机位、二维 / 三维、维度事件。「纸人」= 抠出的她站在世界里；「入画」= 整张插画占满画面且平面是世界的。

### P0 前奏「表紙」0:00–0:14.7（小节 0–7）

1. **地平线**（弱起–1）：全黑。一条极细的冷光线从黑里浮出来——地平线，天和水还分不开。镜头贴着水面，正对地平线，纹丝不动。
2. **两个字**（2–3）：墙后的太阳升起，但我们还看不见墙：黑里亮起两个字「表」「裏」，是穿过镂空的光，长长的倒影从字底下一直拖到镜头脚下的水面上。（D1：文字是光）
3. **墙、窗、她**（4–6）：每个重拍光多一层：先是字周围墙的轮廓，再是窗——窗里是黎明的天（S1）；第 6 小节的重拍，她出现了：一张画出来的人站在窗前的水面上，背对我们、回过头（KV 的姿势），黎明从她背后勾出轮廓，水里是她的倒影。第一次看见她：画出来的人站在真的地方。（D3）
4. **穿窗**（7）：镜头急推向窗玻璃，4 帧穿过玻璃——落进画里：A1，她在窗边，整张画占满画面，画里的窗玻璃就是刚才那片天，云还在走。（D7 → 入画）

### P1 主歌 1「目覚め」0:14.7–0:38.9（小节 8–23）

克制：每小节最多一次维度事件。全部是表的画。

1. **晨光里的她**（8–11）：入画 A1。画里的窗是真的天：镜头缓慢横移两度，窗外的云有视差；光柱里的尘是三维的；她的头发有几根离开了纸面轻轻飘。每个重拍一朵云经过，她脸上的光跟着变（一盏真的灯透过真的窗）。
2. **睁眼**（12–13）：入画 A5（闭眼）换 Q1（睁眼），同一构图。她的瞳孔是镜子：里面倒映着真的天和地平线。（D1）
3. **第一滴**（14–15）：三维微距。窗台上那杯水，黎明在它后面，杯子透亮。第 15 小节的重拍，一滴玫瑰红的墨从画幅上方落下来，落进水里，从水面往下开成一缕羽流。全片第一个颜色。
4. **渗过来**（16–19）：同一种红出现在二维里：入画 Q1，红从她头发的根部渗进纸里（头发那么大、边缘参差、边比中心深），一缕墨在她脸前的空气里往下流（三维）。然后跨维度焦点转移：前景她清楚、后景窗台上的杯子虚；焦点拉过去，她虚成一片白，杯子里的墨在转。（D7）
5. **杯口是海**（20–22）：正上方俯拍杯子：墨在水里转成一个漩。镜头垂直上升，杯口的圆变成——海面上的一圈红：同一个漩，三十米高空往下看，红在墙的倒影旁边铺开，她的纸人小小地站在窗前。杯子就是海。（D7 尺度跳跃）
6. **第一道裂**（23）：最后一拍，一道玫瑰红的细光从红渍处沿水面划开。接 riff。

### P2 riff「ヒビ」0:38.9–0:49.5（小节 24–30）

器乐 riff，能量回升，横移越来越快，每一次跨过维度。

1. **甩镜**（24–27）：每小节一次横甩：从世界（水面、墙、天）甩进一张画的正面，再甩回世界。依次 A2（回头）、A3（对着镜子系领结）、A4（指尖碰窗玻璃）。每张画里的平面都是世界：A3 的镜子里是真的天和地平线，她画出来的倒影留在镜面上；A4 的玻璃是天，指尖碰到的地方玻璃上一圈光的涟漪。
2. **裂**（每个重拍）：一道玫瑰红的裂光，二维和三维交替：水面上、墙的灰泥上、窗玻璃上；画里是划过镜面的一条细线。（D4）
3. **风**（28–29）：天上的云开始跑（S1 快速平移），水面被吹皱，她的发丝全部顺风流，窗台上杯子里的水在抖。
4. **熄**（30）：黎明一拍一拍灭掉，世界黑下去，只剩裂缝里透出的红和两个字的光。

### P3 导歌 1「自問自答」0:49.5–0:55.5（小节 31–34）

她的纸人（Q1，表）站在夜色刚起的水面上，水里的倒影是另一张脸（U2，裏）。镜头在水面高度绕着她转，每拍从她的脸俯到倒影里的脸、再抬回来：第 31 小节一拍一面，第 34 小节半拍一面。两张脸构图相同、方向相反，隔着水线对视。最后一拍，水面从她脚下炸开一圈，镜头扎进水里。（D7 水面高度）

### P4 副歌 1「侵」0:55.5–1:13.6（小节 35–46）

颜色爆发，每拍一次维度事件。每小节的节拍型：
- **第 1 拍**：冲击推进，整帧闪成纸上的负片一帧（D4）；
- **第 2 拍**：水面一圈脉冲环（ドクン），整面水一震（D5）；
- **第 3 拍**：水下一团墨炸开（三维体积，玫瑰红）；
- **第 4 拍**：插入半拍一张副歌插画（入画 C1–C4），再回三维。

镜头每小节换一个，五个轮着来：① 贴着水面朝墙滑行；② 正上方看墨在墙的倒影旁开花；③ **半浸**：镜头一半在水上一半在水下，上半是表的世界（天、墙），下半是裏的深水（墨、光柱），水线横贯画面；④ 穿过墙上的窗飞向地平线，玻璃的反光扫过；⑤ 水下仰看：天透过水面在晃，墙是一个黑影，墨云从旁边涌过。
C1 是副歌的主插画：她在深水里下沉，头发四散，墨像烟一样缠着她——入画时她的水就是这片真的深水，光柱和墨是三维的。
从第 41 小节起，水底亮起红：墨填满了整片海的水下，到第 46 小节，表的白天世界站在一整片裏的红上面。

### P5 副歌 1 后段「溢れ」1:13.6–1:28.7（小节 47–56）

1. **溢出**（47–50）：入画 C1。缠着她的墨顺着她的头发往上升——她的水就是海，墨升到水面，镜头跟着墨从她脸前退出画面、浮出水面：从水上看，红渍在海面上铺开。同一股墨，从二维到三维。（D4）
2. **满**（51–54）：整片海从水底被红照亮，水面上还映着冷的天：一面水，上面是冷的镜子、下面是暖的光。镜头贴水滑行，墙的倒影是红的，每拍一次冲击推进。
3. **拉开**（55）：对着站在窗前的她做全片唯一一次希区柯克变焦：她不动，墙和地平线被拉远。（D7）
4. **断**（56）：黑一拍。然后雨声。

### P6 间奏「雨」1:28.7–1:45.3（小节 57–67）

天换成 S2（雨夜）：世界第一次入夜。

1. **雨落在海上**（57–60）：大远景：雨落在整片海上，满面细环；墙黑着，只有窗里透出一点光；她的纸人（W1，背影，全身）远远站在水面上，很小，淋着雨。镜头从她身后慢慢推近。
2. **她在雨里**（61–63）：W1 的背影渐大，窗里的光在她身后勾出玫瑰色的边，雨从她前面落下，倒影在脚下；全屏入画 W2：她的脸，雨在她脸前落（三维），红从眼角化开（二维）。
3. **绕到侧面**（64–65）：镜头绕着她的纸人转 90°：她变成一条线；再转过去是没画过的纸背和铅笔编号。全片第一次明确告诉观众：她是纸。（D3、D7）
4. **雨变线**（66–67）：重拍上，三维的雨变成二维的速度线一小节，再变回来。最后一拍，镜头俯向水面，看见她的倒影，开始滚转。（D4、D5）

### P7 主歌 2「裏返り」1:45.3–2:07.9（小节 68–82）

世界翻成裏。又回到克制，像梦。

1. **翻转**（68–69）：贴着水面的镜头慢慢滚转 180°：倒影成了真的。夜的天（S2）在上面，水在下面，一切都是黑和玫瑰红。只用这一次。
2. **裏的她**（70–77）：裏的插画入画，和世界交替出现：U1（躺在黑水上，正上方；她的水就是夜的海，每拍一圈环，发丝摊在水面上）；世界（夜的海，墙的剪影，两个字现在透出玫瑰红的光）；U2（抱膝坐在暗处，红光勾边）；世界；U4（咬着拇指指甲的特写）。
3. **倒影是另一个人**（78–81）：她的纸人（Q1，表）站在夜的水上，倒影是裏（U2）。镜头从她的脸慢慢俯过水线到倒着的那张脸；每小节倒影闪回一次表。（D4）
4. **裂**（82）：一道裂光从她脚下沿水面爬开。

### P8 导歌 2「乱反射」2:07.9–2:14.0（小节 83–86）

水面炸成几百片悬在半空的碎片，每一片是一面镜子，映着她的一个瞬间（前面插画的局部）；碎片下面露出发红的深水。镜头在碎片间穿行，半小节一切，每一切先落在负片上，半拍后变成三维（D4）。最后一拍，碎片排成她的剪影。

### P9 副歌 2「あっち」2:14.0–2:32.1（小节 87–98）

她跑起来。

1. **跑**（87–92）：贴水面 24 mm 倒退跟拍。她的纸人（R0）迎着镜头在水面上跑：每一步踩出真的涟漪和水花，发丝向后流，身后的墙越退越远，两个字的光在远处。每个重拍一片水面的碎片擦过镜头。荷兰角每小节换向。（R0 一张画、靠机位和水花卖奔跑；若另画 R1–R6 的跑步循环则一拍二替换。）
2. **冲破画面**（93–96）：入画 R0：她冲向镜头；第 96 小节的重拍，画从中间撕开——全片唯一一次撕她的画——后面是真的夜海和夜空。（D6）
3. **回头**（97–98）：她停下回头（入画 KV'：裏的 KV，夜，红光）。她身后，整片海的水面像一张纸一样被掀起来，立成一面黑色的水墙。

### P10 终段「表裏一体」2:32.1–2:57.7（小节 99–115）

全片最强的段落，同一段旋律唱两遍。

- **第一遍**（99–106）：掀起的海从地平线开始撕开，像纸：撕开的外面是天（S3），天从裂口灌进来；墙成了碎片飞散。她跃起（入画 F1：半空中，一半冷光一半红光，碎纸围着她——碎纸就是撕碎的世界）。镜头跟着她升起，碎纸被吸成一个旋涡。
- **第二遍**（107–115）：同样的东西更密。天在上也在下，水没有了，她在两片天之间；两个太阳，一个冷的一个玫瑰红的，在天的两头。每半小节在二维插画和三维天空之间切一次，最后四小节每拍一切，冷光和红光每拍互换。F2（一只眼被冷光照、一只眼被红光照）在最后一小节的第一拍。最后一拍，旋涡停住，碎纸同时落下，水面回来了，静止。

### P11 尾「裏表紙」2:57.7–3:01（小节 116–结束）

正上方。静止的水面，墙的倒影，倒影里那两个字反过来读：**裏表**。字后面的光一盏一盏灭。最后一拍，黑场，水面上一圈极小的环。

## 7. 三维要做的

| 东西 | 做法 | 来自 v4 的 |
|---|---|---|
| 水 | 大圆盘，近黑的 3 cm 水在黑底上（镜面）；慢纹、脉冲环（节点里的 Value，逐帧）、雨环（噪声驱动的环场）；P8 碎成碎片（碎片各带一张画的局部，Fresnel 玻璃）；P9 末掀起（网格位移成一面墙）；P10 撕开（两半 + 碎纸） | 水材质、`hybrid_fx.water_ring`、`shards`、`halves`、`confetti/scraps` |
| 天 | 穹顶 + S1/S2/S3 自发光，按段切换；两个太阳 | `sky_backdrop` 的做法 |
| 墙 | 灰泥盒 8 × 6 × 0.4，窗洞、钢框、老玻璃、窗台；表 / 裏两个字布尔镂空，字后一排小灯（封底时逐个熄灭） | 大厅的窗和 `cut_letters` |
| 杯 | 玻璃杯 + 水，窗玻璃内侧一块只对透射光线可见的亮板；墨的羽流 | `glass_of_water`、`ink_volume`，第九版定下的参数 |
| 深水 | 水面以下一个体积盒：吸收偏蓝、光柱从水面漏下，墨在里面开花 | 雾的做法 + `ink_volume` |
| 她的纸人 | 每张画跑 anime-seg 得到人物遮罩（`art/v5/figures/`），纸的材质用它做透明，浮雕照旧，发丝照旧；站在水上的纸人脚下 1 cm，侧面一条线，背面白纸 + 铅笔编号 | `paper.py`、`hybrid.py`、`strands` |
| 入画 | 画幅等于画，平面换成世界的（天穹、水、镜子），不再有白边 | `hybrid_mat`、`into()` |
| 倒影是另一个人 | 只对反射光线可见的裏画 | `refl_ura` 的做法 |
| 裂光、负片闪、冲击推进、荷兰角、尘、雨、速度线 | 照旧 | `crack`、`compositor`、`aim`、`motes`、`rain` |

不再使用：大厅、挂画的排、钢丝和夹子、舞台印刷、牛皮纸板、墙倒下露出天、表裏字从 KV 上镂空。

## 9. 制作顺序

1. 三张定帧：**黎明**（墙、两个字的光、窗前的她、海）；**雨夜**（W1 站在雨里的水面上，窗里一点红）；**水线**（她的脸和倒影里裏的脸同框）。确认世界成立再动镜头。
2. 人物遮罩（anime-seg），纸人的材质。
3. 动态分镜 v5：`animatic_v5.py` 按第 5 节重写镜头表，640 px 出一版看总览图。
4. 1280 / 32 全片，按 docs/hybrid.md 的流程审、改、并排实验。
5. 1920 / 48 成片。
